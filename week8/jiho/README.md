# PWM이 뭐임?

디지털 출력은 원래

High/Low 두 상태만 만들 수 있음

근데 이 두개를 빠르게 전환하면

```
3.3V ┌────┐    ┌────┐    ┌────┐
     │    │    │    │    │    │
0V ──┘    └────┘    └────┘    └──
```

이런식으로 사각파를 만드는게 가능함

여기서 두 가지가 중요한데

## Frequency 주파수

주파수는 한 주기가 반복되는 속도를 의미하며 단위는 Hz다.

예를들어 440Hz라면 1초동안 High/Low 패턴이 440번 반복된다.

## Duty Cycle

한 주기 중 High 또는 활성 상태가 차지하는 비율.

```
50% Duty

HIGH ─────
          │
LOW       └─────

      50%  50%
```

이 Duty 비율을 바꿔 LED밝기나 모터 속도 조절이 가능하다.

# PWM을 어케 만드는데?

STM32에서는 CPU가 직접

```
GPIO HIGH
delay
GPIO LOW
delay
```

이걸 반복하지 않음

대신 Timer peripheral이 PWM을 하드웨어적으로 발생시킴

구조를 보면

```
Timer Clock
    ↓
  PSC
Prescaler
    ↓
Counter
0 → 1 → 2 → ... → ARR
    ↓
CCR과 비교
    ↓
PWM 출력
```

이렇게 됨

핵심 레지스터는 다음 세개

| 값  | 역할                  |
| --- | --------------------- |
| PSC | 타이머 입력 클럭 분주 |
| ARR | PWM 한 주기 길이      |
| CCR | Duty Cycle결정        |

여기서 PSC와 ARR은 저번주 TIMER하면서 공부 했음

PWM 주파수는 기본적으로 $f_{\text{PWM}}=\frac{f_{\text{TIM}}}{(PSC+1)(ARR+1)}$
이다.

Duty Cycle은 PWM Mode 1기준 대략

$Duty = \frac{CCR}{ARR+1} \times 100$

## CCR이 뭐임?

이게 저번주에 발표하려다 못한 내용임

CCR을 통해서 PWM 조절이 가능함

예를들어서 
```
ARR=999
CCR=500
```

이라고 한다면 
CNT가 500이 될때까지는 HIGH 이후에는 LOW를 유지한다

따라서 Duty=50%가 됨

## ARR과 CCR의 차이
```
ARR → PWM의 전체 주기
CCR → 그 주기 안에서 HIGH가 얼마나 유지될지
```

그래서 Duty를 75% 하고 싶다면 CCR을 750 으로 하면 됨

다만, 이게 중요한 점이 Cnt가 UP, DOWN, UP&DOWN 중 뭐냐에 따라서 달라짐

Up에서는 ARR이 999 일때 CCR에 따라서 몇 % duty인지 정해진다 볼 수 있지만

Down에서는 100- ccr/arr*100 의 duty임 

이유는 UP에서는

```
CNT
0          300                         999
|-----------|---------------------------|
    HIGH                 LOW
```

DOWN에서는

```
999                         300          0
 |---------------------------|-----------|
             HIGH                 LOW
```
이렇기 때문임

심지어 Up&Down에서는 또 다름

CRR이 한 주기에 두번 발생함

```
CNT

999               ▲
                  / \
                 /   \
CCR=300 --------●-----●--------
               /       \
              /         \
0 ───────────            ───────
```
이렇기 때문에 처음 0-300 HIGH 301-999, 99-301 LOW 300-0, 0-300 HIGH를 반복함

그래서 따져보면 총 2000중 600 HIGH 1400 LOW로 30% Duty를 가지게 됨

## 근데 왜 굳이 UP & Down 씀? 불편하잖아

왜냐면 가운데 정렬 PWM이 만들어지기 떄문임

Edge-aligned (UP or DOWN)에서는 PWM edge가 한쪽 기준으로 몰려있음

```
CH1
┌───┐
│   │
┘   └────────

CH2
┌──────┐
│      │
┘      └─────
```
반면 Center-aligned 에서는
```
CH1
────┌───┐────
    │   │
────┘   └────

CH2
───┌─────┐───
   │     │
───┘     └───
```
이렇게 가운데를 기준으로 대칭이 됨 이렇게 하면 전력 스위칭에서 특점 시점에 변화가 몰리는 현상을 줄이는데 유리함

그리고 **모터제어, 인버터, 전력전자**에서는 Center-aligned PWM이 많이 쓰임

또 CCR은 하나의 레지스터만 있는 게 아님 여러개가 존재함 CCR1,2,3,4

그리고 모터제어에서는 3상 모터 이런게 있음

3상 모터는 간단하게 서로 다른 3개의 전기 신호를 이용해 회전 시키는 모터임

```
U상
V상
W상
```

3상 모터는 뭐 회전 자기장을 자연스럽게 만들 수 있어 토크가 부드럽고 효율과 출력 특성이 좋아서 쓴다고 하는데 뭐 이건 그냥 그런거구나 하면 되고 어쨌든 실무나 이런데 들어가면 이런걸 써야한다고 생각하면 됨

아무튼 이게 3개의 코일에 각각 다른 전압을 걸어서 자기장을 발생 시켜야하는데 만약 U, V, W를 PWM으로 제어한다고 할 때, Edge-aligned로 한다면

```
U  ┌────┐
   │    │
───┘    └────────

V  ┌───────┐
   │       │
───┘       └─────

W  ┌──────────┐
   │          │
───┘          └──
```
이렇게 특점 시점에 스위칭 변화가 몰리는 상황이 자주 나올 수 있음 그 순간 전류 변화가 커지고 노이즈도 커질 수 있음

근데 Center-aligned로 하면 PWM이 주기의 가운데를 기준으로 대칭임

```
U  ────┌────┐────
       │    │
───────┘    └───────

V  ──┌────────┐──
     │        │
─────┘        └─────

W  ─┌──────────┐─
    │          │
────┘          └────
```

이렇게 하면 스위칭 시점이 더 대칭적으로 배치됨 

그리고 모터제어에서는 전류 측정이 중요함

3상 모터는 U,V,W 전류를 측정해서 제어함. 근데 MOSFET이나 IGBT가 ON/OFF 되는 순간은 노이즈가 큼

```
스위칭 순간
   ↓
───┐
   │
   └────────────
   ↑
노이즈 큼
```

그래서 ADC로 전류를 읽을땐 스위칭 순간을 피하려함

Center-aligned에서는

```
edge                   edge
 ↓                       ↓
──┐                   ┌──
  │                   │
  └───────────────────┘
           ↑
       ADC 측정하기 좋은 구간
```
이렇게 중앙에 안정적인 측정 구간을 만들기가 쉬움

아무튼 뭐 더 말하면 뇌절하는 것 같고 여기까지만 뇌절하겠음

아무튼 Up & Down으로 해야 3상모터와 같은거를 CCR1,2,3 이렇게 사용해서 하기 좋다고 생각하면 됨


# 타이머를 1MHz로 만드는 방법
TIM3에 들어오는 클럭 84MHz 기준

PSC를 83으로 설정하면  1MHz가 된다.

즉 TIMER Counter가 1초에 1,000,000번 증가

이렇게 만들어놓으면 이후 계산이 편함

예를들어 도=261.63 Hz라면 

$ARR = \frac{1,000,000}{261.63} - 1$

약 ARR=3821임.

Duty를 50%로 만드려면 CCR= 약 1911 정도 주면 됨 

Duty는 음의 높낫이랑 관계없음 높낮이는 PWM과 관련이 있음

그럼 도를 만들려면 ARR=3821 주고 레는 1,000,000 / 293.66 - 1 주면 되고 뭐 이런식으로 주파수는 대충 검색해서 찾아보고 ARR 값 변경해주면 됨

그리고 ARR을 미리 계산 해 놓는 것 보다는
