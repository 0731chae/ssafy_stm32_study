## 스타트업 코드(Startup Code) vs 부트 코드(Boot Code)

스타트업 코드(Startup Code)와 부트 코드(Boot Code)는 시스템이 켜진 후 메인 프로그램이 실행되기까지 과정을 담당한다는 공통점이 있으나, 수행하는 역할과 실행 시점, 범위에서 차이가 있습니다.

---

### 부트 코드 (Boot Code)

* **정의**: 전원이 켜진 직후 하드웨어가 가장 먼저 실행하는 최초의 진입점(Entry Point) 코드입니다.
* **역할**: CPU 리셋 벡터(Reset Vector)에서 가장 먼저 호출되어, CPU 동작 모드 설정, 아주 기본적인(Minimum) 메모리(RAM/ROM) 및 클럭 초기화, 그리고 메인 펌웨어나 부트로더를 실행 가능한 메모리 영역으로 로드하는 역할을 합니다.
* **특징**: 시스템 전반의 하드웨어 생명주기 중 가장 맨 처음에 동작합니다.

---

### 스타트업 코드 (Startup Code)

* **정의**: C언어의 `main()` 함수가 실행되기 직전에 필요한 런타임 환경을 구축하는 어셈블리/C 코드입니다.
* **역할**:
  * 스택(Stack) 및 힙(Heap) 메모리 영역 설정
  * 전역 변수 및 정적 변수 초기화 (BSS 영역을 0으로 초기화, 초기화된 데이터 영역을 ROM에서 RAM으로 복사)
  * 인터럽트 벡터 테이블(Interrupt Vector Table) 설정
* **특징**: 흔히 `crt0.s`(C Runtime 0) 등으로 불리며, 소프트웨어(C언어 런타임) 관점의 시작을 준비합니다.
