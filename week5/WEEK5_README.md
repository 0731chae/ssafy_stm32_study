## 📝 5주차 과제
- 인터럽트의 개념과 임베디드 시스템에서의 인터럽트의 필요성에 대한 정리
- 인터럽트와 Polling의 차이에 대한 정리
- **과제** : polling과 interrupt 방식으로 각각 버튼 입력받기
 - **hint!** : delay를 길게 주게 되면 인터럽트와 polling의 차이를 눈에 띄게 볼 수 있습니다!

**원래는 SPI/I2C 인터페이스를 5주차에 다루려 했으나, 센서가 많이 갖춰졌을 때 해 보는 것이 적절하다고 생각되어서 나중에 임베디드 키트를 받은 후에 해당 내용을 다루겠습니다!**
**또한 인터럽트 개념은 임베디드 시스템 전반에서 꽤 중요한 내용이라 약 2~3주간 다룰 예정이니, 발표 준비하시는 분들이나 과제 수행하실 때 부담 가지지 말고 참고하시면 되겠습니다 ^_^**
