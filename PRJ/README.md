### 프로젝트 소개

STM32F446RE를 활용하여 MCU 미니 프로젝트를 진행합니다.

지난 10주 동안 학습했던 MCU 관련 지식과 기술을 실제 시스템에 적용해 보는 프로젝트입니다. 관심 있었던 분야나 평소 만들어보고 싶었던 시스템을 자유롭게 구현하시면 됩니다.

**이번 프로젝트에서는 구현한 시스템의 규모나 기능의 복잡성보다, 하나의 시스템을 요구사항 정의부터 설계, 구현, 통합 및 테스트까지 체계적으로 개발하는 경험을 더 중요하게 생각합니다.**

프로젝트 규모는 작아도 괜찮습니다! 부담 가지지 마시고, 간단한 시스템이라도 개발 프로세스를 따라 직접 설계하고 구현해 보는 데 집중해 주세요.

기존에 배부한 센서와 소자 외에 필요한 부품을 추가로 구매하셔도 무관하며, 필요에 따라 Raspberry Pi 등 AP 보드를 함께 활용하셔도 됩니다. 다만 STM32 MCU가 시스템의 핵심 기능을 담당하도록 구성해 주세요.

### 프로젝트 제한사항

**1. 개발 환경 및 형상관리**
- 팀별 GitHub Repository 생성 및 활용
- STM32F446RE 기반 시스템 구현

**2. 기술 요구사항**
- 통신 인터페이스 최소 1개 이상 활용 (SPI, I2C, UART, CAN 등)
- MCU Peripheral 기능 최소 1개 이상 활용 (Interrupt, DMA, PWM, Timer 등)
- 센서 최소 1개 이상 활용

**3. 프로젝트 관리 및 개발 프로세스**
- Jira Kanban을 활용한 작업 관리 권장
  - Notion, GitHub Projects 등 다른 도구 사용 가능
- 개발 프로세스 모델 중 하나를 선택하여 적용 (V-Model, Agile 등)
- 요구사항 정의 → 설계 → 구현 → 통합 → 테스트 과정을 수행
- 요구사항과 테스트 케이스 간 연관성을 명시

### 프로젝트 진행 시 권장사항

- 본격적인 구현 전에 요구사항과 시스템 아키텍처를 먼저 정의해 주세요.
- 팀원별 모듈 책임과 인터페이스를 협의한 뒤 개발을 시작해 주세요.
- **기능 구현 후에 테스트를 고민하기보다, 개발 전에 테스트 기준을 정의해 보세요.**
  - 나중에 수정하셔도 괜찮습니다! 하지만 설계 단계에서 테스트에 대한 설계도 같이 들어가면 정말 이상적인 개발 프로세스입니다 :)
- **개발 과정에서 발생한 문제와 해결 과정을 GitHub 또는 프로젝트 관리 도구에 기록해 주세요.**
- 최종 발표에서는 단순 기능 시연뿐 아니라 설계 의도, 테스트 결과, 개선 사항을 공유해 주세요.
